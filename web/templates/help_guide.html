Daily use

Recommended working procedure

  1. Start small. Upload 10 cases first.
  2. Check the generated YAML. Confirm that every Excel condition has an action or assertion.
  3. Check the user state. Anonymous users may see ads and Subscribe. Subscribers should not.
  4. Run the selected flows. Use Run Selected Now in Flows or run a saved suite.
  5. Trust a pass only when conditions are asserted. Opening the app alone is not enough.
  6. Rerun a failure alone. Correct automation problems before reporting an application bug.
  7. Use the Testing Bot. Ask about cases, locators, user states, failures, and suggested fixes.
User states

Expected differences

  • Anonymous: not signed in; ads and Subscribe can appear.
  • Registered: signed in but without an active subscription.
  • Subscriber: active subscription; no ads or Subscribe upsell.
  • Expired: signed in, but subscription renewal may be required.
Failure decision

Automation issue or app bug?

  • Wrong or missing locator → automation issue.
  • Element is off-screen and no scroll exists → automation issue.
  • Wrong account state or test data → setup issue.
  • Timeout or disconnected device → environment issue.
  • Correct flow fails repeatedly with verified evidence → possible application bug.

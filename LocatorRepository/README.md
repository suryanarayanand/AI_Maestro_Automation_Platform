# Locator repository

The repository separates extracted candidates from device-validated locators.

- `smart_locator_repository.json`: hierarchy-extracted locator candidates.
- `validated_locator_repository.json`: approved locators used for final YAML generation.
- `validated_locator_repository.csv`: human-readable export generated by `locator_registry.py`.

Validated locator record:

```json
{
  "name": "home_tab",
  "screen": "home",
  "locator": {
    "type": "id",
    "value": "nav_home",
    "priority": 1
  },
  "status": "validated",
  "validated_at": "2026-07-31T12:00:00",
  "source": "home_top_20260731_120000.json",
  "notes": "Verified on Android"
}
```

Priority order is resource ID, accessibility label, stable text, indexed selector,
then coordinates as a last resort. Extracted candidates must not be promoted until
they have been exercised successfully on the connected device.
